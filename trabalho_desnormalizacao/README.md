## Como visualizar
Abra `index.html` no navegador. A página é estática e não precisa de servidor para visualização local.

## Como publicar com GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie os quatro arquivos para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione publicação a partir de uma branch, escolha `main` e `/ (root)` e salve.
5. Copie a URL gerada e substitua `[URL_DO_REPOSITORIO]` no rodapé por ela.
6. Teste a URL em uma janela anônima e em um celular.

## Roteiro sugerido para 5 minutos
- 1 minuto: problema e conceito de desnormalização.

- 2 minutos: mostrar o SQL e a cópia do nome do cliente.
